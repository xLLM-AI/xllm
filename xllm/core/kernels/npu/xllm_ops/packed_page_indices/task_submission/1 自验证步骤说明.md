# 1 自验证步骤说明

## 1. 环境

| 项目 | 值 |
|---|---|
| 硬件 | 昇腾 Atlas A3（Ascend 910C），单逻辑 NPU |
| 操作系统 | Linux-5.10.0-182.0.0.95.r2220_156.hce2.aarch64-aarch64-with-glibc2.39 / aarch64 |
| CANN | cann-9.1.0（ASCEND_HOME_PATH=/home/developer/Ascend/cann-9.1.0） |
| Python | 3.11.14 |
| PyTorch | 2.10.0 |
| torch_npu | 2.10.0.post4 |
| triton-ascend | 3.2.2 |
| triton | 3.5.0 |
| 设备名 | Ascend910_9362 |
| triton target | GPUTarget(backend='npu', arch='Ascend910_9362', warp_size=0) |
| C++ 扩展 | built |

依赖：CANN Toolkit 9.1.0、PyTorch、torch_npu、triton-ascend、gcc/g++、Ninja。
主机侧 C++ 扩展由 `solution.py` 在首次导入时用 `torch.utils.cpp_extension.load`
构建；也可提前执行 `python build_ext.py`。

## 2. 目录

```text
solution.py              # prepare/run 接口与 Triton Ascend 核
csrc/packed_ext.cpp      # 主机侧 C++ 扩展
build_ext.py             # 扩展预构建入口
task_pkg/                # 发布包（case.json、golden.py、generate_data.py 等）
selftest/                # 自测与报告生成代码
task_submission/         # 自验证材料（本目录）
```

## 3. 构建

```bash
source ~/Ascend/ascend-toolkit/set_env.sh
export LD_LIBRARY_PATH=/usr/local/Ascend/driver/lib64:$LD_LIBRARY_PATH
python build_ext.py
```

## 4. 运行全部自测

```bash
python -m selftest.run_all
```

该命令依次执行：

1. 官方功能/工程入口 `golden.py --verify-functional`（14 个正向用例、8 项非法输入、
   动态更新、双 stream、storage 重绑定、内存回收、大单层用例）。
2. `generalization` 四个补充用例及输出 SHA-256 核对。
3. 主性能用例与 route 用例的配对计时（预热 50 次、6 轮 × 200 次、bootstrap 10000 次，
   seed=20261031，线性分位数）。
4. 内存检查（双 stream、保留输出独立性、20 次释放回收、峰值增量）。
5. 生成 `result.json`、`generalization.json`、三份 xlsx 报告与日志。

## 5. 单独运行

```bash
# 官方功能/工程检查
python task_pkg/golden.py --verify-functional   --implementation "$PWD" --output "$PWD/logs/functional_result.json"

# 性能
python -m selftest.performance

# 内存
python -m selftest.memory
```

## 6. 判定

- 14 个正向用例与 8 个负向检查全部通过；
- `packed_perf_small` 提交均值 ≤ 40 us；
- `packed_perf_large` 提交均值 ≤ 75 us；
- 两个主性能用例的配对均值差、中位数差 > 0，bootstrap 95% CI 下限 > 0；
- route 用例逐值一致并提交配对计时；
- 内存：20 次释放回收后活跃分配回到测量前水平，输出独立存储。

## 7. 原始数据

`task_submission/` 保存 `result.json`、`generalization.json`、`environment.json`、
`2.2 精度自验证日志.log`、`3.2 性能自验证日志.log`、`4.2 内存自验证日志.log`。
