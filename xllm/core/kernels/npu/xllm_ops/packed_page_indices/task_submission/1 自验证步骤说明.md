## 3. 获取代码与构建

```bash
git clone https://github.com/Fun10165/xllm-packed-page-indices.git
cd xllm-packed-page-indices
git checkout v1.0-task06

python3 -m pip install -r requirements.txt
python3 build.py
```

`build.py` 预期输出一行 `.so` 路径，例如：

```text
built packed_page_indices_host at .../host/build/packed_page_indices_host.so
```

主机扩展只在第一次 `prepare` 或 `build.py` 时编译；之后命中 `host/build` 缓存。首次编译约 26 秒。

## 8. 复现注意事项

1. NPU 环境必须先 `source set_env.sh`，否则 `torch_npu` 找不到 `libhccl.so`。
2. `golden.py --output` 的目标文件必须不存在。
3. 主机扩展依赖 Ninja；`host/build_host.py` 会在 PATH、`~/.local/bin`、解释器 `bin` 下查找。
4. 计时期间不要运行其他 NPU 任务；若设备受干扰，按任务书要求保留日志并重新测量。
5. `prepare` 不计入计时；所有计时都走 `prepared.run`。
