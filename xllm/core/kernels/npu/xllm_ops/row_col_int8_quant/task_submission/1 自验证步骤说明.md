# 自验证步骤说明

## 验证环境

910C / Ascend910_9382，CANN 9.1.0，驱动 25.5.t6.b001；aarch64 openEuler 24.03 LTS-SP3，Python 3.12.13，torch 2.10.0+cpu，torch_npu 2.10.0.post4+git5dd8ef3。镜像：`quay.io/jd_xllm/xllm-ai:xllm-dev-cann9.1.0-a3-openeuler24.03-py3.12`。详细机器与版本信息见 environment.json，源码校验见 source_manifest.json。所有命令通过 SSH 在该开发环境执行。

## 构建、安装和测试

在本解答目录执行 `bash verify_all.sh`；或按以下顺序执行：

```bash
source /usr/local/Ascend/cann-9.1.0/set_env.sh
python3 tools/build_aclnn.py
bash build.sh
export ASCEND_CUSTOM_OPP_PATH="$(pwd)/aclnn_install/vendors/community_task2${ASCEND_CUSTOM_OPP_PATH:+:$ASCEND_CUSTOM_OPP_PATH}"
./build/run_aclnn_example 0
./build/run_example 0
python3 tests/run_tests.py --task-dir tests/task
python3 tests/task/verify.py --solution-file python/solution.py --report task_submission/public_accuracy.json
python3 tests/run_audit.py
python3 tests/run_engineering.py --task-dir tests/task
python3 tests/run_benchmark.py --task-dir tests/task
python3 tests/check_acceptance.py
```

构建过程在英文临时目录中进行，安装仅写本工程自己的目录，不覆盖系统 CANN。运行已有产物前仍须加载 CANN 环境和本题 ASCEND_CUSTOM_OPP_PATH。

## 验收内容与证据

27 个公开用例在 Kernel 直调、直调框架和正式 ACLNN 入口上分别核对独立 CPU 标杆；公开验证器另行复核 ACLNN。输出必须位于输入 NPU，形状、dtype、连续性正确，独立存储且不修改输入。精度门槛见 docs/任务书.md。

39 次非法输入/属性拒绝检查、24 次额外种子与非零存储偏移检查，以及验证器自身的三项反例检查，见 audit.json / audit.log。并发、提前释放输入、重复 20 次回收和内存峰值见 engineering.json / 4.2 内存自验证日志.log。缓存题额外检查连续追加。

性能预热 50 次、每轮 200 次、共 5 轮，比较双方分配新输出的 API 到设备完成耗时，各轮平均值再取中位数。内存使用预热后、输入已存在时的 PyTorch 活跃张量峰值增量，含输出和 ACLNN 实际工作区；不代表整卡 HBM。工作区不得漏记 CANN 系统部分。

三份 Excel 分别逐行对应 accuracy.json、performance.json、engineering.json；原始日志保留真实运行输出。check_acceptance.py 同时检查用例完整性、各项状态、性能协议、每个阈值和内存回收。失败必须返回非零退出码。
